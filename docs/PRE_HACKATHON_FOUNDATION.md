## Required verification before transferring assets

1. Verify actual source paths, versions and hashes; mark unverified entries as unverified.
2. Exclude all keys, private client material and sensitive geolocations.
3. Check copyrights, data licenses, source redistribution permission and third-party model/API terms.
4. Capture immutable baseline references **where available**. A commit made today does not prove the historical creation date of external files.
5. Retain all failed tests and known limitations, not only successful screenshots.
