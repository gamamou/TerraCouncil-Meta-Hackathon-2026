## Completion rule

For each implemented feature, record:
- First relevant commit SHA, authored/committed timestamps and PR.
- Exactly what was **newly built** versus reused.
- Meta model ID/version, invocation method and redacted execution evidence.
- FSDC evidence IDs, license and scientific validation state.
- Test command, results and reproducibility instructions.
- Human review and remaining limitations.

**Never backdate commits, relabel experiments as deployed features, or present a reused pre-hackathon audio/visual clip as newly created functionality.**
