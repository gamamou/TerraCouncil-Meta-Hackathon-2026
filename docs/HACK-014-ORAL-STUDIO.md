# HACK-014 — French Oral Studio in Edge

This is an incremental development of the same FAITH / TerraCouncil application. It does **not** launch Meta models or ElevenLabs automatically.

## What is new

- `GET /api/oral-draft?id=<run>` returns a short source-checked, French, four-speaker **editorial reconstruction** bound to a completed scientific trace and unchanged FSDC evidence fingerprint.
- An **Atelier oral** in the Edge Chamber displays four editable speakers and their French texts. It counts characters and requires explicit human confirmation that the text's meaning has been compared against the original model positions.
- `POST /api/oral-approve` refuses unreviewed, source-mismatched, malformed or unsupported text and saves an approved source-bound manifest in:
  `Documents/TerraCouncil-Hack008-Sessions/Approved-Oral-Reviews/`.
- The filenames include the session ID and an abbreviated hash, so previous approvals are not overwritten.
- The audio synthesizer from HACK-011 still refuses an unapproved draft. **No paid synthesis has been executed in this milestone.**
- The UI preserves the independently verified four-scene debate; PDF V3 remains available.
- The approval is editorial only, NOT independent scientific or field validation.

## Test the browser review without any paid calls

1. Stop the current local server in VS Code with Ctrl+C.
2. Download the latest repository ZIP, extract it, open the new folder in VS Code.
3. Find the latest server, check that its source contains the HACK-014 route, and launch it:

```powershell
$ErrorActionPreference = "Stop"
$env:PYTHONUTF8 = "1"
$server = Get-ChildItem . -Recurse -File -Filter "local_council_server.py" | Select-Object -First 1
if (-not $server) { throw "Server not found" }
$root = $server.Directory.Parent.FullName
if (-not (Select-String -Path $server.FullName -Pattern "/api/oral-approve" -Quiet)) {
    throw "HACK-014 not present; update the ZIP"
}
$evidence = Join-Path $HOME "Documents\TerraCouncil-Scientific-Inputs\boke_screened_evidence.json"
python -X utf8 -m unittest discover -s (Join-Path $root "tests") -p "test_browser_oral_review.py" -v
if ($LASTEXITCODE -ne 0) { throw "HACK-014 review tests failed" }
python -X utf8 "$($server.FullName)" --evidence "$evidence" --port 8765
```

4. Open `http://127.0.0.1:8765` in Edge.
5. Use **Retrouver mes sessions** → **Ouvrir cette session** for the already completed HACK-008 session. Do NOT create a new model debate for this test.
6. Scroll to **Chambre de délibération** → **Atelier oral · Relecture française**. Click **Ouvrir le scénario de cette session**. Read all four blocks, optionally edit the `text_to_review` prose. Review the original four model outputs in the section above.
7. If you affirm the editorial fidelity, tick the explicit review checkbox and click **Approuver et enregistrer localement**. This creates a JSON manifest in the Approved-Oral-Reviews directory with zero paid calls. The file is not a scientific sign-off.

## Optional ElevenLabs synthesis remains separately gated

Use the connected standalone `src/render_session_audio.py` only after explicit approval, data rights review and acceptance of a potentially billed ElevenLabs call. It requires `--approved-manifest`, `--session`, `--evidence`, `--out-dir`, `--send-to-elevenlabs`, `--i-reviewed-script`, and `--i-approve-cost-and-sharing`, plus local environment variables `ELEVENLABS_API_KEY`, `TERRA_VOICE_SPARK`, and `TERRA_VOICE_WONDER`. Never share keys in chat. A paid call might be charged even if it times out, so never retry blindly. The resulting MP3 and timing JSON can be loaded in the session-matched Edge player.
