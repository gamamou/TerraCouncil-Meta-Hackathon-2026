# TERRA-DATA-002M — Dust-science decision protocol in the existing HACK-016 live council

Implemented on 2026-10-28. No additional atmospheric measurements, model responses or paid API calls have been generated by this milestone.

## Scientific position

The existing FSMI CAMS September 2026 data contain 10 regional air-quality model points (PM10, PM2.5, dust, aerosol optical depth), approximately 45 km grid. Existing wind archives have 720 modeled hourly values at 10 sampling centers. The AERMOD reference is a successful US EPA **SO2** sample numerical match, not a validated Boké mine PM dispersion case. None of these establishes mine contribution, personal exposure, regulatory compliance or a field-monitored site concentration.

## Integrated functionality

- `src/faith_dust_decision_protocol_002m.py`: four falsifiable investigation threads: emission inventory, receptor and baseline monitoring, meteorology plus dispersion validation, effectiveness and side effects of mitigation. Each has a missing-input requirement, proposed method and decision it could inform. This is a decision *methodology*, not a report of completed measurements.
- `src/faith_dust_context_002l1.py`: attaches the four-thread protocol when a dust question has three validated context entries and still marks local dust concentration as absent.
- `src/dynamic_council.py`: plan fingerprint includes `scientific_protocol_sha256` so the preview-specific plan consent cannot be silently reused with a changed protocol.
- `src/dynamic_runtime.py`: the protocol is passed to each proposer, independent Wonder critic and final Spark synthesis; saved in the durable run trace. Prompt instructs to critique preconditions, preserve scope limits and avoid claims about observed on-site concentrations.
- `src/local_council_server.py`: existing `/api/dynamic-preview` reports full protocol, dust context count and protocol fingerprint. The existing `/api/dynamic-run` retains separate `consent` and `share` flags, exact plan-hash/evidence-hash checks, model key and no-blind-retry checkpoint logic.
- `tests/test_faith_dust_debate_002m.py`: four regression tests using synthetic AOI evidence and mocked Spark/Wonder responses, zero network requests and zero paid calls. Tests have been published but have not been executed on the user's Windows machine in this turn.

## What will happen in Edge

For the Boké multidomain question, the preview can show the existing *AOI-screened* WorldCover/WorldPop records, additional FAITH regional context including CAMS, wind and AERMOD, explicit missing local dust topic, four proposed investigation questions, models to be used and model-call budget. A separate explicit user action is required to launch live Spark-Wonder; context does not magically become an observed dust finding. The first live session after this change must be compared to the pre-existing HACK-016 2026-10-28 benchmark debate for quality, exact references and overclaims, then reviewed before ElevenLabs oral synthesis.
